# Active Context: Текущий контекст и статус

## 1. Текущее состояние проекта
Бэкенд NurCRM для сферы услуг полностью спроектирован, реализован и протестирован в директории `backend/`:
- Созданы все 12 микросервисов со слоями `domain`, `application`, `infrastructure`, `interface`.
- Реализованы общие библиотеки `libs/common` (Python) и `libs/go_common` (Go).
- Разработан SQL-скрипт инициализации PostgreSQL 16 (`deploy/init-db/01_init.sql`) с изоляцией схем, созданием ролей `svc_*`, GiST exclusion constraint для исключения накладок и таблицами transactional outbox/inbox.
- Настроен единый Nginx Gateway (`deploy/nginx/nginx.conf`), обеспечивающий проксирование как новых путей `/api/v1/...`, так и legacy-путей (`/api/barbershop/...`, `/api/users/...`, `/api/construction/...`).
- Создан файл оркестрации `deploy/docker-compose.yml`.
- Написаны подробные руководства: `ARCHITECTURE.md`, `API_REFERENCE.md`, `DEPLOYMENT.md`.

---

## 2. Недавние решения и корректировки
- **Удален симлинк `бэк`:** оставлена только чистая папка `backend`, расположенная непосредственно рядом с исходными ТЗ.
- **В `Money` добавлены операторы сравнения:** добавлены методы `__lt__`, `__le__`, `__gt__`, `__ge__` для безопасных вычислений цен, скидок и начислений.
- **Созданы `wsgi.py` файлы:** добавлены входные точки WSGI для всех Django-сервисов (`auth`, `catalog`, `client`, `schedule`, `booking`, `finance`, `admin-panel`).
- **Все автоматические тесты проходят успешно:**
  - Python: 11 тестов (100% PASS)
  - Go: тесты доступности и объединения слотов (100% PASS).
- **Файлы `.gitignore`, `.env.example` и `.env`:** Созданы на уровне корня проекта, директории `backend/` и каждого из 12 микросервисов. Конфигурация проверена через `git status`, секреты исключены из коммитов, а примеры шаблонов готовы к командной разработке.
- **Исправление правил Gitignore для Go-сервисов:** Из всех файлов `.gitignore` удалены имена сервисов `public-gateway`, `realtime-gateway`, `scheduler-worker`. Вместо них добавлены стандартные директории сборки `bin/` и `dist/`. Все исходные коды Go-сервисов гарантированно отслеживаются Git, а бинарники исключены.
- **Оркестрация одной командой:** В корне проекта и в директории `backend/` настроен `docker-compose.yml`. Команда `docker compose up -d` запускает все 16 контейнеров. Работоспособность и взаимодействие сервисов через Nginx Gateway (порт 80) проверены сквозными тестами.
