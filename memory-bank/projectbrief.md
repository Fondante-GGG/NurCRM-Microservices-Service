# Project Brief: NurCRM Backend для сферы услуг

## 1. Назначение проекта
**NurCRM для сферы услуг (Services Sector CRM)** — высоконадежный программный комплекс для автоматизации операционной деятельности предприятий в сфере персональных и бытовых услуг (барбершопы, салоны красоты, массажные и SPA-центры, косметологические и оздоровительные клиники).

Основан на техническом задании:
- `TZ_CRM_SERVICES_SPHERE.md` — общая бизнес-логика и реверс-инжиниринг CRM сферы услуг.
- `ТЗ Backend CRM для сферы услуг (1).md` — техническая архитектура бэкенда, правила изоляции схем, Clean Architecture, саги и многопользовательская работа.

---

## 2. Основные цели и задачи
1. **Интерактивный журнал расписания:** исключение накладок в графиках специалистов, сетка с шагом 15/30 мин, фиксация статусов.
2. **Публичный виджет онлайн-бронирования 24/7:** пошаговый мастер записи для клиентов, алгоритм Availability Engine, поддержка выбора «Любой мастер».
3. **Единая база клиентов (CRM):** валидация телефонов, дедупликация, карточка клиента, история визитов, защищенное хранилище медицинских карт, фото и договоров на диске.
4. **Сдельная оплата труда мастеров:** гибкие процентные ставки за услуги, автоматические начисления при завершении визита ($price \times rate / 100$), выплаты и баланс.
5. **Финансовый и складской учет:** открытие и закрытие кассовых смен с фиксацией остатков и выручки, учет сопутствующих товаров и списание расходных материалов.
6. **Управленческая аналитика:** расчет среднего чека, выручки, конверсии записей, рейтингов мастеров и услуг, графиков посуточных денежных потоков.
7. **Панель управления платформой (Django Admin):** безопасный доступ сотрудников поддержки к данным всех сервисов через мультибазовый роутер с обязательным аудит-логом.

---

## 3. Границы проекта
- **Входит в объем:** 
  - Все 12 сервисов бэкенда (DRF, FastAPI, Go), общие библиотеки `libs/common` и `libs/go_common`.
  - Скрипт инициализации БД PostgreSQL 16 с разделением по 9 изолированным схемам и сидами для стейджинга.
  - Пользовательский фронтенд `front-usluga` (Next.js 16, React 19) с журналами, услугами, клиентами и аналитикой.
  - Интеллектуальный AI-Консультант с каскадным переключением провайдеров (Gemini ➔ Claude ➔ OpenAI).
  - Единый Nginx Gateway, Docker Compose оркестрация, автоматические тесты и документация.
- **Вне границ (будущие этапы):** Мобильные приложения iOS/Android, прямой онлайн-эквайринг (этап 4 дорожной карты).
