# NurCRM — сайт (front-usluga)

Новый интерфейс сайта NurCRM: Next.js 16, TypeScript, Tailwind 4. Начали с программы «Услуги».

## Запуск

```bash
npm install
cp .env.example .env.local   # адрес сервера и настройки входа
npm run dev                  # http://localhost:3000
```

Проверка типов: `npx tsc --noEmit`. Сборка: `npm run build`.

## Как устроено

- `src/app/login/` — общая страница входа для всех программ (услуги, склад, маркет, производство).
  Сейчас спрятана: `AUTH_ENABLED = false` в `src/lib/config.ts`, сайт сразу открывает «Услуги».
- `src/app/api/auth/` — вход и выход. Браузер ходит сюда, а не на сервер NurCRM напрямую:
  токен лежит в httpOnly-cookie. Сервер после входа сам называет программу (`src/lib/nurcrm.ts`,
  функция `pickSection`); если не назвал — страница `/razdel` с выбором вручную.
- `src/app/(app)/[section]/[page]/` — все экраны программ. Адрес: `/usluga/zapisi`.
- `src/lib/menu.ts` — меню каждой программы: группы и пункты с иконками. Новый экран = пункт
  здесь + перевод в `src/i18n/translations.ts` (ru и ky обязательны) + страница.
- `src/components/shell.tsx` — каркас: сворачиваемая левая панель (состояние запоминается),
  шапка, на телефоне — шторка.
- Цвета и шрифт (Montserrat) — в `src/app/globals.css`.

## Примерные данные

Пока сервера нет, экраны работают на примерных данных (`src/data/sample/seed.ts`): они создаются в браузере
и хранятся в localStorage, поэтому записи и чеки, сделанные на презентации, сохраняются между перезагрузками.
Кнопка «Сбросить примерные данные» — в Настройках. Правила расчёта зарплаты: `src/lib/payroll/calc.ts`,
проверка примеров: `node scripts/payroll-check.ts`.

Новый аккаунт начинается с мастера настройки (сфера, приём клиентов, название). Сферы и их стартовые
услуги: `src/lib/industry.ts`. Сменить сферу потом может только техподдержка (`/support`).

## Заливка на Vercel (для показа по ссылке)

1. Зарегистрироваться на vercel.com (через GitHub удобнее всего) и залить этот репозиторий на GitHub.
2. В Vercel: «Add New → Project», выбрать репозиторий, ничего не менять (Next.js определяется сам), «Deploy».
3. Через минуту будет адрес вида `front-usluga.vercel.app`. Каждый `git push` в main обновляет сайт.

Или из терминала: `npx vercel` (попросит войти в аккаунт), затем `npx vercel --prod`.
