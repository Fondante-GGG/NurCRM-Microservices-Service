# ТЗ: модуль «Аренда помещений» в Кезек

Oct 25, 2026 · @Сыймык Рыскулов

## 1. Цель и границы

Нужно добавить в Кезек новую сферу «Аренда помещений» для владельцев торговых центров и всех, кто сдаёт помещения. Поведение и вид каждого экрана показаны в [кликабельном прототипе](https://claude.ai/artifact/3emFVngBmMP8zm7QWeTTZp): если текст ТЗ и прототип расходятся, прав текст, а спорное выносится в открытые вопросы.

**Кто пользуется:**

| Роль | Что делает в системе |
| --- | --- |
| Владелец | Видит всё, задаёт доступы, смотрит аналитику, меняет реквизиты |
| Управляющий ТЦ | Ведёт помещения, арендаторов, договоры |
| Бухгалтер | Касса, расходы, зарплата, акты сверки |
| Администратор | Шахматка, арендаторы, договоры, уведомления |
| Кассир | Приём оплат и чеки |
| Арендатор | В версии 1 в систему не входит, получает SMS и документы |

**В версию 1 входит:** шахматка помещений, арендаторы, договоры с шаблонами, касса с чеками, акт сверки, расходы и налоги, сотрудники и зарплата, аналитика, уведомления, филиалы, настройки и доступы.

**В версию 1 не входит:** личный кабинет арендатора, онлайн-оплата картой, фискализация чеков через ККМ (ГНС), интеграция с 1С и банком. Под них нужно оставить место в модели данных.

## 2. Общие требования

### 2.1 Компания и филиалы

- Все данные принадлежат компании (аккаунту владельца). Данные разных компаний не пересекаются.
- У компании один или несколько филиалов (ТЦ, здание). Помещения, договоры, оплаты, расходы и сотрудники привязаны к филиалу.
- В шапке есть выбор филиала и пункт «Все филиалы». Все списки, итоги и аналитика фильтруются по выбранному филиалу. В прототипе так сделана только шахматка, в продукте нужно везде.

### 2.2 Вход и доступы

- Вход по телефону или email и паролю. Восстановление пароля кодом из SMS. Если в Кезек уже есть своя авторизация, использовать её.
- Доступ выдаётся по разделам. Владелец видит всё всегда, сотрудник видит только отмеченные владельцем разделы.
- Разделы: Аналитика, Филиалы, Шахматка, Арендаторы, Договоры, Уведомления, Касса, Расходы и налоги, Сотрудники, Настройки.
- Проверка доступа делается на сервере для каждого запроса, а не только скрытием пунктов меню. Закрытый раздел отдаёт 403.
- Готовые наборы прав заполняют галочки одним нажатием, после чего их можно поменять вручную:

| Набор | Разделы |
| --- | --- |
| Управляющий | все, кроме Настроек |
| Бухгалтер | Аналитика, Договоры, Касса, Расходы, Сотрудники |
| Администратор | Шахматка, Арендаторы, Договоры, Уведомления |
| Кассир | Арендаторы, Касса |
| Только шахматка | Шахматка |
| Без доступа | нет, вход закрыт |

- Все изменения денег, договоров и доступов пишутся в журнал действий: кто, что, когда, старое и новое значение.

### 2.3 Деньги, даты, язык

- Валюта — сом (KGS). Суммы хранить целым числом в тыйынах, не float.
- В интерфейсе формат «4 700 с», в юридических документах «4 700 сом» и сумма прописью.
- Даты «25 октября», время «14:15», часовой пояс Бишкека (UTC+6).
- Язык интерфейса русский. Тексты вынести в файлы перевода, чтобы потом добавить кыргызский.

### 2.4 Внешний вид

Интерфейс делается по брендбуку Кезек и повторяет прототип.

- Шрифт Montserrat. Тёмное боковое меню #2F3024 с группами, фон #F5F1E8, карточки #FFFDF8, линии #E6E0CF.
- Одна главная золотая кнопка на экране (#C2A26B, текст #1F2018).
- Статусы: в порядке #DDEBE1/#2F6B4A, скоро оплата #F3E8CF/#7E6129, просрочка #F6E0D8/#A4432C, бронь #ECEDE0/#4A4C36, свободно — пунктир.
- Только светлая тема, без эмодзи и «!», обращение на «вы».
- На телефоне (от 360 px) меню выезжает по кнопке, страница не прокручивается вбок, широкие таблицы листаются внутри своего блока.

## 3. Функции по разделам

Меню сгруппировано так: Аналитика, Филиалы; «Помещения» (Шахматка, Арендаторы, Договоры); «Деньги и команда» (Касса, Расходы и налоги, Сотрудники); «Система» (Настройки). Уведомления открываются колокольчиком в шапке рядом с профилем.

### 3.1 Шахматка помещений

- Сетка по этажам: каждая клетка — помещение с номером, площадью и арендатором. Цвет клетки = статус: свободно, сдано, скоро оплата, просрочка (с числом дней), бронь.
- Сверху 4 показателя: заполняемость (% от площади), начислено за месяц, получено, долг арендаторов.
- Фильтры по статусу и этажу со счётчиками.
- Клик по занятому помещению открывает карточку арендатора. Клик по свободному открывает карточку помещения с кнопками «Сдать» (запускает мастер договора), «Изменить», «Удалить».
- «+ Помещение»: филиал, этаж, номер (подставляется следующий свободный), тип, площадь м², ставка за м², бронь. Номер уникален внутри филиала.
- Типы по умолчанию: Бутик, Островок, Офис, Склад, Фуд-корт, Рекламное место. Пункт «+ Свой тип» добавляет тип в справочник компании.
- Нельзя удалить помещение с действующим договором. Удаление подтверждается вторым нажатием.

### 3.2 Арендаторы

- По умолчанию таблица: арендатор, помещение и площадь, контакт, аренда, долг, договор до («через N дн.» или «истёк»), взыскания, статус. Внизу итоги по аренде и долгу. Переключатель «Таблица / Карточки».
- Поиск по имени, помещению, телефону; фильтры Все / Просрочка / Скоро оплата / Оплачено; сортировка по клику на заголовок.
- Карточка арендатора: реквизиты и контакты, помещения, условия договора, долг и пеня, история оплат за 4 месяца, напоминания, взыскания.
- Кнопки в карточке: «Принять оплату», «Напомнить» (SMS / WhatsApp), «Акт сверки», «Договор», «Взыскание».
- Взыскания: тип (Замечание, Предупреждение, Выговор, Штраф), дата, текст, кто вынес, сумма штрафа (необязательно), флажок «уведомить арендатора». Штраф увеличивает долг и попадает в акт сверки.

### 3.3 Договоры и шаблоны

- Два вида договоров: аренды и трудовые. У каждого своя база и свои шаблоны.
- База договоров: номер, сторона, помещение или должность, срок, сумма, шаблон, статус (действует, скоро истекает, истёк, черновик). Открытие договора показывает готовый текст для печати и скачивания (PDF, DOCX).
- Шаблоны: список, создание, редактирование, копия, удаление (нельзя удалить шаблон, по которому есть договоры, только в архив). Загрузка из файла .docx или .txt.
- В шаблоне поля пишутся как {{поле}}. Редактор имеет панель полей: клик вставляет поле в курсор. Специальные строки: #  заголовок по центру, ##  раздел, [[подписи]] и [[подписи-работник]] блок подписей.
- Поля аренды: номер_договора, дата, город, объект, арендодатель, директор, арендатор, тип_арендатора, инн, подписант, паспорт, телефон, деятельность, помещение, этаж, площадь, ставка, аренда_в_месяц, начало, окончание, срок_мес, день_оплаты, депозит, пеня, индексация, коммунальные, сумма_договора. Для трудовых добавляются сотрудник, должность, оклад, график, дата_приёма, телефон_сотрудника.
- Реквизиты арендодателя и директор берутся из Настроек. При .docx-импорте поля в файле должны распознаваться, даже если Word разбил {{поле}} на несколько кусков.
- Мастер договора аренды, 4 шага: 1) помещение (только свободные в выбранном филиале); 2) арендатор (ИП / ОсОО / физлицо, ИНН, подписант, паспорт, телефон); 3) условия (ставка, срок, день оплаты, депозит, пеня, индексация, коммунальные); 4) выбор шаблона и предпросмотр. Заполненные поля подсвечены, незаполненные отмечены красным. «Подписать» создаёт арендатора и договор, помещение становится сданным.
- Договор с сотрудником составляется из карточки сотрудника или из раздела «Договоры → Трудовые» по тому же принципу.
- Уже подписанный договор хранит снимок текста: правка шаблона или реквизитов потом его не меняет.

### 3.4 Касса и чеки

- Операции за день и за месяц: приход зелёным со знаком «+», расход терракотой со знаком «−». Остатки по способам: наличные, банк, QR / Элкарт и кошельки.
- Приём оплаты: арендатор, сумма (подставляется долг), способ, дата, флажок «Добавить пеню». Прочий приход (реклама, парковка) принимается без арендатора.
- После оплаты аренды сразу формируется чек: номер по порядку, дата и время, реквизиты компании, арендатор, помещение, за какой период, сумма и пеня отдельными строками, способ, кассир, остаток долга. Чек можно напечатать (ширина 80 мм), скопировать текстом и отправить в WhatsApp / SMS.
- Любой чек открывается повторно из списка операций и из карточки арендатора. Оплату нельзя удалить, только сторнировать с причиной (право только у владельца).

### 3.5 Акт сверки (обязательно)

- Формируется из карточки арендатора за выбранный период.
- Таблица: дата, документ, дебет (начислена аренда, пеня, штраф), кредит (оплаты с номером чека). Сальдо на начало, обороты, сальдо на конец и фраза «задолженность в пользу … составляет … сом».
- Подписи директора и бухгалтера из Настроек, место подписи арендатора. Печать, PDF, отправка арендатору.
- Каждый сформированный акт сохраняется с номером и датой, чтобы его можно было найти потом.

### 3.6 Расходы и налоги

- Журнал расходов: дата, категория, описание, сумма, способ оплаты, филиал. Итоги по категориям за месяц.
- Категории по умолчанию: Налоги, Коммунальные, Зарплата, Непредвиденные, Обслуживание. Пункт «+ Новая категория» добавляет свою.
- Налоговый календарь: ближайшие платежи с датой и суммой, отметка «оплачено».
- Амортизация: список основных средств (название, стоимость, дата покупки, срок в годах), ежемесячная сумма и остаточная стоимость. Амортизация входит в расходы для прибыли, но не в движение денег.
- Итог месяца: начислено, прочий доход, расходы, амортизация, чистая прибыль.

### 3.7 Сотрудники и зарплата

- Список: ФИО, должность, телефон, дата приёма, график, оклад, премия, трудовой договор.
- Ведомость за месяц: начислено, удержано (Соцфонд и подоходный), на руки, аванс, к выплате, взнос работодателя. Итоги и полная стоимость персонала.
- Кнопки «Выплатить аванс» и «Выплатить зарплату» создают расход в категории «Зарплата».
- У каждого сотрудника кнопка «Доступ»: галочки по разделам, готовый набор, логин (телефон). При первом доступе сотрудник получает SMS со ссылкой и временным паролем. Снять все галочки = закрыть вход и завершить его сеансы.
- «Посмотреть глазами сотрудника»: владелец видит меню и разделы так, как их увидит сотрудник, с полосой «Вернуться к владельцу». Это только просмотр, входа под сотрудником не происходит.

### 3.8 Аналитика

Разделена кнопками на 5 вкладок, каждая показывает только своё:

| Вкладка | Что показывает |
| --- | --- |
| Обзор | Выручка, расходы, прибыль, заполняемость, долг и что требует внимания |
| Выручка | Начислено и собрано за 12 месяцев, собираемость %, выручка по этажам и типам, способы оплаты |
| Расходы | Расходы по категориям, динамика по месяцам, доля от выручки, персонал |
| Арендаторы | Топ должников, дисциплина оплат, истекающие договоры, взыскания |
| Помещения | Заполняемость по месяцам и этажам, простаивающие помещения и потерянная аренда |

Период выбирается (месяц, квартал, год), филиал берётся из шапки. В прототипе история за прошлые месяцы задана вручную; в продукте она считается из начислений, оплат и расходов.

### 3.9 Уведомления

- Колокольчик в шапке со счётчиком (просрочка + скоро оплата). Скрыт, если у сотрудника нет доступа к разделу.
- Страница: должники с суммой, днями и пеней; скоро оплата; истекающие договоры. Кнопки «Напомнить» и «Напомнить всем».
- Автоматические правила (каждое включается отдельно): за 3 дня до срока; в день оплаты с суммой и реквизитами; каждые 3 дня просрочки арендатору и копия владельцу в Telegram; начисление пени с 1-го дня просрочки; за 45 дней до конца договора напоминание владельцу.
- Каналы: SMS, WhatsApp, Telegram. Каждая отправка пишется в историю напоминаний арендатора со статусом доставки.

### 3.10 Филиалы

- Список филиалов с адресом, количеством помещений, заполняемостью и начислениями.
- «+ Филиал»: название, город, адрес, тип объекта, число этажей, управляющий, телефон. После создания открывается пустая шахматка с подсказкой добавить помещения.
- Редактирование филиала. Удалить можно только пустой филиал.

### 3.11 Настройки

- **Реквизиты компании:** наименование, ИНН, ОКПО, юридический адрес, директор (ФИО полностью), главный бухгалтер, банк, БИК, расчётный счёт, телефон, email. Подставляются в договоры, чеки, акты и напоминания. ИНН 14 цифр, БИК 6 цифр, счёт 16 цифр.
- **Профиль и пароль:** имя, телефон, email; смена пароля (текущий, новый, повтор; не меньше 8 символов и хотя бы одна цифра); дата последней смены; «Выйти из аккаунта». После смены пароля другие сеансы завершаются.
- **Доступ сотрудников:** таблица «сотрудник × раздел» с галочками и логином. Клик по строке открывает ту же форму доступа, что и в «Сотрудниках». Раздел «Настройки» по умолчанию открыт только владельцу.
- **Вход:** экран входа на тёмном фоне с логотипом, поля «Телефон или email» и «Пароль», ссылка «Забыли пароль?». После 5 неверных попыток — пауза 15 минут.

## 4. Модель данных

Ниже минимальный набор сущностей. Названия таблиц и полей разработчик сводит с текущей схемой Кезек (компания, филиал, пользователь, сотрудник, вероятно, уже есть). Все суммы в тыйынах (integer), у всех сущностей есть company_id, created_at, created_by.

| Сущность | Ключевые поля | Связи |
| --- | --- | --- |
| Company | наименование, ИНН, ОКПО, адрес, директор, бухгалтер, банк, БИК, счёт, телефон, email | имеет филиалы, пользователей |
| Branch | название, город, адрес, тип, этажей, управляющий, телефон | Company |
| Unit (помещение) | номер, этаж, тип, площадь м², ставка за м², бронь (до даты, на кого) | Branch, UnitType |
| UnitType | название, системный или свой | Company |
| Tenant (арендатор) | название, форма (ИП / ОсОО / физлицо), ИНН, контактное лицо, паспорт, телефон, вид деятельности | Company |
| Lease (договор аренды) | номер, начало, конец, аренда в месяц, день оплаты, депозит, пеня %/день, индексация %, коммунальные, статус, снимок текста | Tenant, Unit (одно или несколько), Template |
| Charge (начисление) | вид (аренда, пеня, штраф, коммунальные), период, сумма, срок оплаты | Lease |
| Payment (оплата) | дата и время, сумма, способ, кассир, статус (проведена / сторнирована), причина сторно | Tenant (или пусто для прочего прихода), Branch |
| PaymentAllocation | сумма | Payment → Charge (какие начисления закрыла оплата) |
| Receipt (чек) | номер по порядку, снимок содержимого | Payment (1:1) |
| ReconciliationAct | номер, период с/по, сальдо на начало и конец, снимок строк | Tenant |
| Remark (взыскание) | тип, дата, текст, кто вынес, сумма штрафа | Tenant; штраф создаёт Charge |
| Reminder | дата, канал, текст, авто или вручную, статус доставки | Tenant |
| ReminderRule | вид правила, включено | Company |
| Template | вид (аренда / трудовой), название, текст, исходный файл, архивный | Company |
| Expense | дата, сумма, описание, способ | Branch, ExpenseCategory |
| ExpenseCategory | название, системная или своя | Company |
| TaxPayment | налог, срок, сумма, оплачено | Company; оплата создаёт Expense |
| Asset (основное средство) | название, стоимость, дата покупки, срок лет | Branch |
| Employee | ФИО, должность, телефон, дата приёма, график, оклад, премия | Branch; договор → EmploymentContract |
| EmploymentContract | номер, дата, снимок текста | Employee, Template |
| Payroll / PayrollLine | месяц, даты аванса и расчёта; на сотрудника: начислено, удержания, аванс, к выплате, выплачено | Employee |
| User / Access | логин (телефон), хеш пароля, роль (владелец / сотрудник), список разделов, филиалы, активен | Employee (для сотрудника) |
| AuditLog | кто, что, объект, старое и новое значение, время | любая сущность |

Долг и статус арендатора не хранятся, а считаются из Charge и Payment. Два договора на одно помещение с пересекающимися датами запрещены.

## 5. Бизнес-правила и расчёты

Все расчёты делает сервер, интерфейс только показывает результат. Ставки налогов и пени хранятся в настройках, а не в коде.

### 5.1 Аренда и начисления

- Аренда в месяц = площадь помещений × ставка за м², если в договоре не задана другая сумма.
- 1-го числа каждого месяца система создаёт начисление аренды по всем действующим договорам со сроком оплаты = день оплаты из договора. Первый и последний неполные месяцы считаются пропорционально дням.
- Индексация: раз в год с даты начала договора аренда растёт на указанный %. Владелец получает уведомление за 30 дней.
- Депозит = аренда × число месяцев из договора. Хранится отдельно и не считается выручкой.

### 5.2 Долг, статус и пеня

- Долг = сумма начислений с наступившим сроком − сумма проведённых оплат.
- Оплата сначала закрывает самые старые начисления, потом текущий месяц. Переплата остаётся авансом на следующий месяц.
- Статус арендатора и его помещений:
  - **Просрочка:** есть неоплаченное начисление с прошедшим сроком. Дни просрочки считаются от самого старого такого срока.
  - **Скоро оплата:** до срока оплаты текущего месяца осталось 7 дней или меньше, и оно не оплачено.
  - **В порядке:** долга нет.
  - Свободное помещение с бронью — **Бронь**, без брони — **Свободно**.
- Пеня начисляется, если включено правило, с 1-го дня просрочки. Ставка берётся из договора (по умолчанию 0,1% в день):

$$
\text{Пеня} = \text{Долг} \times \text{ставка в день} \times \text{дней просрочки}
$$

- Пеня показывается как расчётная сумма. В долг она попадает только когда кассир отметил «Добавить пеню» или владелец выставил её вручную (тогда создаётся Charge «пеня»). Пеня на пеню не начисляется.
- Договор с датой окончания в прошлом показывается как «истёк», а не отрицательным числом дней. За 45 дней до конца — метка «скоро».

### 5.3 Зарплата (Кыргызстан)

Ставки в прототипе: Соцфонд работника 10%, подоходный налог 10%, взнос работодателя 17,25%. Перед запуском их должен проверить бухгалтер (стандартный вычет и льготы в прототипе не учтены).

$$
\begin{aligned}
\text{Начислено} &= \text{Оклад} + \text{Премия} \\
\text{Соцфонд} &= \text{Начислено} \times 10\% \\
\text{ПН} &= (\text{Начислено} - \text{Соцфонд}) \times 10\% \\
\text{На руки} &= \text{Начислено} - \text{Соцфонд} - \text{ПН} \\
\text{Аванс} &= \text{Оклад} \times 40\%,\ \text{округление до 100 сом} \\
\text{К выплате} &= \text{На руки} - \text{Аванс} \\
\text{Взнос работодателя} &= \text{Начислено} \times 17{,}25\%
\end{aligned}
$$

Аванс выплачивается 10-го, расчёт в последний день месяца (даты меняются в настройках). Удержания и взнос работодателя попадают в налоговый календарь.

### 5.4 Прибыль и показатели

$$
\text{Прибыль} = \text{Начислено аренды} + \text{Прочий доход} - \text{Расходы} - \text{Амортизация}
$$

- Амортизация в месяц = стоимость / (срок в годах × 12), линейно, до нулевой остаточной стоимости.
- Заполняемость = сданная площадь / вся площадь филиала. Бронь считается свободной.
- Собираемость = получено за месяц / начислено за месяц.
- Потерянная аренда = площадь свободных помещений × их ставка.

### 5.5 Нумерация

- Договоры аренды, трудовые договоры, чеки и акты нумеруются отдельно, сквозно в рамках компании, без пропусков. Формат договора аренды: А-2026/031.

## 6. Нефункциональные требования

- Модуль встраивается в текущее приложение Кезек как новая сфера бизнеса: общие аккаунты, авторизация, филиалы и дизайн-система, без отдельного продукта.
- Страница открывается быстрее 2 секунд на филиале до 500 помещений и 5 000 оплат в год.
- Пароли хранятся только в виде хеша (bcrypt или argon2). Все запросы по HTTPS.
- Деньги и документы не удаляются физически: сторно или архив, с записью в журнал.
- Резервная копия базы ежедневно.
- Документы (договор, чек, акт) выгружаются в PDF и печатаются из браузера; договор также в DOCX.
- Фоновые задачи (начисления 1-го числа, автонапоминания) идемпотентны: повторный запуск не создаёт дублей.

## 7. Этапы разработки

Предлагаемый порядок; каждый этап можно показать клиенту отдельно. Сроки оценивает разработчик.

1. **Основа:** филиалы, помещения, шахматка, арендаторы, договор (без шаблонов), ежемесячные начисления, реквизиты компании.
2. **Деньги:** касса, оплаты и разнесение, чеки, долг, пеня, акт сверки, взыскания.
3. **Договоры:** шаблоны, импорт .docx, мастер с автозаполнением, PDF и DOCX.
4. **Расходы и команда:** расходы, налоговый календарь, амортизация, сотрудники, зарплата, трудовые договоры.
5. **Доступы:** вход сотрудников, права по разделам, просмотр глазами сотрудника, журнал действий.
6. **Уведомления и аналитика:** автоправила, SMS / WhatsApp / Telegram, аналитика из 5 вкладок.

Если доступы уже есть в Кезек, этап 5 сводится к добавлению новых разделов в существующую систему прав.

## 8. Критерии приёмки

- [ ] Новое помещение появляется на шахматке своего филиала со статусом «Свободно».
- [ ] Мастер создаёт договор по выбранному шаблону, все {{поля}} заполнены, помещение становится «Сдано».
- [ ] Шаблон из .docx с полями загружается и даёт правильно заполненный договор.
- [ ] 1-го числа начисления создаются ровно один раз по каждому действующему договору.
- [ ] На следующий день после срока неоплативший арендатор красный на шахматке, есть в уведомлениях, пеня посчитана по формуле.
- [ ] Частичная оплата сначала закрывает старый долг; чек показывает остаток долга.
- [ ] Акт сверки за период сходится с карточкой: сальдо на конец = текущий долг. Штраф из взыскания есть в акте.
- [ ] Сотрудник с набором «Кассир» видит в меню только «Арендаторы» и «Касса»; прямой запрос к аналитике отдаёт 403.
- [ ] После смены пароля старый не подходит, новый подходит; другие сеансы завершены.
- [ ] Изменение реквизитов видно в новых чеках и договорах, старые подписанные документы не меняются.
- [ ] Аналитика по филиалу и «Все филиалы» сходится с кассой и расходами за тот же период.
- [ ] На телефоне 360 px все разделы работают без горизонтальной прокрутки страницы.
